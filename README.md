# 📈 Tracker de Métricas de Marketing — Gratis

Herramienta práctica para medir, controlar y optimizar el rendimiento 
de tus campañas de marketing mes a mes. Diseñada para equipos de marketing, 
emprendedores y dueños de negocio que quieren tomar decisiones basadas 
en datos reales y no en suposiciones.

---

## ✅ ¿Qué incluye esta versión gratuita?

- Control de las 8 métricas clave de marketing
- Seguimiento de campañas por canal
- Cálculo automático de ROI por campaña
- Semáforo de rendimiento por métrica
- Vista mensual de resultados
- Fácil de usar — sin conocimientos técnicos

---

## 📊 Métricas incluidas

| Métrica | Qué mide |
|---------|----------|
| 👥 Alcance total | Personas que vieron tu contenido |
| 🖱️ Clics totales | Personas que hicieron clic |
| 📊 CTR % | % de personas que hicieron clic |
| 🛒 Conversiones | Ventas o acciones completadas |
| 💰 Costo por clic | Cuánto pagas por cada clic |
| 🎯 Costo por conversión | Cuánto cuesta cada venta |
| 📈 ROI % | Retorno sobre la inversión |
| ⭐ Tasa de conversión % | % de clics que se convierten |

## 🚀 ¿Cómo usarlo?

1. Descarga el archivo `tracker-marketing-basico.xlsx`
2. Abre con Excel o Google Sheets
3. Ingresa el nombre y presupuesto de cada campaña
4. Registra los resultados reales de cada canal
5. El ROI y las métricas se calculan automáticamente
